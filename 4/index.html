Part 2

In this part, I used a neural field to represent the LEGO vehicle in 3d space. To this end, I created several functions.

transform(c2w, x_c) converted coordinates from camera to world using matrix multiplication

pixel_to_camera(K, uv, s) converted pixels to camera coordinates by solving a linear system of equations defined as s*uv = K*xc for xc.

pixel_to_ray(K, c2w, uv) found the origin and direction vector for a pixel in relation to a pinhole camera. The origin vector could be found through c2w, and the direction vector was found through matrix multiplication with c2w and the pixel.

sample_rays randomly sampled N rays from each image, and sample_along_rays randomly sampled points in a given range along the ray. Below, we can see what 10 points sampled along a randomly generated ray for each image look like.

For the model, I followed the recommended implementation, which features 8 dense layers and a split into a density and color output. I used a coordinate positional encoding frequency of 10 and a direction positional encoding frequency of 4. I trained my model for 1000 epochs, each with 10000 rays.
